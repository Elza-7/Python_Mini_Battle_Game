# ⚔️ Python Mini Battle Game

A beginner-friendly command-line battle game built using Python. Fight an enemy, perform random attacks, heal yourself, and try to win the battle!

## 🎮 Features

- **Random Attack:** Deal random damage between 10 and 20.
- **Critical Hit:** 20% chance to deal double damage.
- **Healing System:** Restore 20 health points.
- **Enemy Counterattack:** The enemy attacks after your actions.
- **Health System:** Both player and enemy start with 100 health.
- **Escape Option:** Escape from the battle whenever you want.
- **Play Again:** Restart the game and fight again.

## 🛠️ Technologies Used

- Python 3
- Random Module
- Functions
- While Loops
- If-Else Conditions

## ▶️ How to Run

1. Install Python 3.
2. Clone this repository:

   ```bash
   git clone YOUR_GITHUB_REPOSITORY_URL
   ```

3. Open the project folder.
4. Run the game:

   ```bash
   python battle_game.py
   ```

## 🎯 Game Controls

| Option | Action |
|---|---|
| 1 | Attack |
| 2 | Heal |
| 3 | Escape |
